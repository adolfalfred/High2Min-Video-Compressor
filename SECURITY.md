# Security policy

## Supported releases

Only the latest release listed on the GitHub Releases page receives security fixes.

## Reporting a vulnerability

Please use this repository's **Security → Report a vulnerability** private reporting form. Do not disclose an unpatched vulnerability in a public issue.

## Verifying downloads

Download binaries only from this repository's Releases page. Each binary archive includes a SHA-256 sidecar and a GitHub Actions provenance attestation. Follow [the download verification guide](docs/download-and-verify.md) before opening an unsigned release.
